Real finding #1 — scatter chart is mislabeled, not broken.
"187 categories" for 5000 rows of (length, reaction_count) is the tell: the chart plugin always groups by x-value and aggregates y (sum by default) — the same logic that's correct for line/bar. For a scatter plot meant to show a relationship between two variables, that's wrong: it collapsed every message into one summed point per unique length value, instead of plotting 5000 individual (x,y) pairs. The chart rendered, but it's not answering "is there a relationship" honestly — it's answering "what's the total reactions per message-length bucket," which is a different question. This is an architecture gap, not a crash — worth either fixing (scatter should plot raw pairs, no aggregation) or documenting as a known limitation.

Real finding #2 — relative dates silently fail.
Both "last month" and "last week" returned 0 rows and the agent said "no data for that period" — technically true, but misleading. The actual reason is structural: the dataset's dates end around mid-June 2026, and CURRENT_DATE in the container is the real current date — so "last week" relative to now never overlaps the dataset at all. The agent has no awareness of this and just reports an honest-sounding but unhelpful empty result instead of noticing "this dataset doesn't cover anything recent" and saying that.
